# BreakMind Platform

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd breakmind-platform
```

2. Install dependencies:
```bash
pnpm install
```

### Running the Project

Start the development server:
```bash
docker compose up
```

### The access endpoints

```bash
http://localhost:8080/health -- api
http://localhost:8000/health -- oracle
http://localhost:3000/ -- landing
```
